## Files

### 1. `q1a.y`

Recognizes strings containing one or more `0` characters followed by the same number of `1` characters.

### Grammar

```text
S → 0S1 | 01
```

### Valid Examples

```text
01
0011
000111
00001111
```

### Invalid Examples

```text
011
001
0101
0001111
```

### Main Change from `q2.y`

The production rule is changed to:

```text
S → 0S1 | 01
```

The important change is:

```diff
- '0' S
+ '0' S '1'
```

This ensures that every `0` introduced at the beginning has a corresponding `1` at the end.

---

## 2. `q1b.y`

Recognizes strings consisting of one or more `a` characters, followed by one or more `b` characters, and ending with a single `c`.

### Grammar

```text
S → aS | aB
B → bB | bC
C → c
```

### Valid Examples

```text
abc
aabc
abbc
aaabbc
```

### Invalid Examples

```text
ac
abb
bc
aabbcc
```

### Main Changes from `q2.y`

The original `S` production is replaced with:

```text
S → aS | aB
```

Two additional non-terminals are introduced:

```text
B → bB | bC
C → c
```

The lexer is also changed to recognize:

```diff
- '0' and '1'
+ 'a', 'b' and 'c'
```

# How the Programs Work

Both programs use YACC to perform syntax analysis.

The general structure is:

```text
%{
    C declarations
%}

%%
    Grammar rules
%%

    C functions
```

### `yylex()`

The `yylex()` function reads characters from the keyboard using `getchar()` and returns them as tokens to the YACC parser.

A newline character is returned as `0` to indicate the end of the input.

### `yyparse()`

`yyparse()` is generated by YACC. It attempts to match the input against the grammar rules.

The main function checks its result:

```c
if (yyparse() == 0)
    printf("Accepted\n");
else
    printf("Rejected\n");
```

A return value of `0` means the input was successfully parsed.

# Summary of Changes

| Program | Grammar Change                          | Lexer Change         |
| ------- | --------------------------------------- | -------------------- |
| `q1a.y` | `S → 0S1 \| 01`                         | Accept `0`, `1`      |
| `q1b.y` | `S → aS \| aB`, `B → bB \| bC`, `C → c` | Accept `a`, `b`, `c` |

The overall YACC structure, `main()`, `yyerror()`, and input-handling approach are kept similar to `q2.y` to make the programs easy to understand and compare.
